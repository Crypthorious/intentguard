Rugwall (formerly IntentGuard)

Rug, price and copy-trade firewall for NEAR trading agents

An AI trading agent proposes a swap. Rugwall checks it for a rug-shaped token, a quote that is off the live pool price, a copied wallet with an insider track record, and the human's spending caps. Only then does it sign an ed25519 verdict. The NEAR contract stores the guard's public key and refuses any settle without a fresh, unused signature, so an agent that skips the guard can't settle, even inside its caps.

Everything on this page is read live from public NEAR testnet RPC and the public NearBlocks API, except the guard verdict log, which is the saved output of the last live testnet demo run. This page never asks for a wallet, a key or any personal data.

  4. Do: clone the repo and run ./run.sh. See: 27 contract tests, 53 guard tests and RESULT: 13/13 scenarios as expected. It works offline too: the demo falls back to fixtures and says so.

What is real here

  • Real, on testnet: the Rust contract, its caps, the kill switch, the function-call key limited to settle, and on-chain ed25519 verification of every guard verdict, with replay and expiry protection.
  • Real, read-only, mainnet data: the 1Click quote (dry: true, so no deposit address and no funds), Ref Finance pool 4512 reserves, and the ft_metadata of USDC and wNEAR.
  • Fixtures: the two meme tokens (goodmeme.pump, rugmeme.pump) and the copied-wallet histories.
  • Not done: settle records the spend and emits an event. It does not forward to intents.near or move tokens. No mainnet, no real money.
